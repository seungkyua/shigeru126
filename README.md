# 시게루 1:2:6 매매 신호 알리미

후지모토 시게루(藤本茂)의 **1:2:6 분할 매매법**을 일봉 데이터로 시뮬레이션하고, 입력한 종목에 대해 **오늘 사야 하는지, 팔아야 하는지**를 알려주는 커맨드라인 프로그램입니다.

| 하고 싶은 일 | 실행할 프로그램 |
|---|---|
| 특정 종목의 1:2:6 신호 보기 | `python common/shigeru_126.py 005930` |
| 전 종목에서 매수를 시작할 종목 찾기 | `python firstbuy/shigeru_start.py --amount 9000000` |
| 내 매매 기록으로 지금 살/팔 수량 확인 | `python buynsell/shigeru_portfolio.py` |
| KOSPI·KOSDAQ 종목 리스트 갱신 | `python stock/stock_list.py` |

모든 명령은 **프로젝트 루트(`shigeru126/`)에서 실행**하는 것을 기준으로 적었습니다. 다른 위치에서 실행해도 동작하며, `python -m firstbuy.shigeru_start`처럼 모듈로 실행해도 됩니다. 디렉토리 구성은 [10. 파일 구성](#10-파일-구성)을 참고하세요.

> ⚠️ 이 프로그램은 투자 판단의 참고용입니다. 신호의 정확성이나 수익을 보장하지 않으며, 실제 매매에 대한 책임은 본인에게 있습니다.

---

## 1. 매매 규칙

투자금을 **총 9단위(1 + 2 + 6)** 로 나누어 단계적으로 매수하고, 역순으로 단계적으로 매도합니다.

### 매수 (반드시 순서대로 진행)

| 단계 | 조건 | 매수량 | 누적 보유 |
|---|---|---|---|
| 1단계 | RSI(14)가 30 **아래로 내려갈 때** (전일 ≥ 30 → 당일 < 30) | 1 | 1/9 |
| 2단계 | MACD가 시그널선을 **골든크로스** | 2 | 3/9 |
| 3단계 | 종가가 일목균형표 **구름 상단을 상향 돌파** | 6 | 9/9 |

- 앞 단계가 체결되지 않으면 다음 단계 신호는 무시합니다. 예를 들어 RSI 30 하회 없이 MACD 골든크로스만 나오면 매수하지 않습니다.
- 하루에 한 단계만 진행합니다.

### 매도 (9/9 풀포지션이 된 뒤에만 작동, 순서대로)

| 단계 | 조건 | 매도량 |
|---|---|---|
| 1단계 | MACD 데드크로스 | 1 (한 번만) |
| 2단계 | RSI(14)가 50 미만 | 2 (한 번만) |
| 3단계 | 종가가 일목균형표 구름을 **이탈** | 남은 물량 **전량** |

- 매수처럼 **앞 단계 매도가 나와야 다음 단계로** 넘어갑니다. 예를 들어 6 매수 직후 구름 이탈이 나와도 MACD 데드크로스가 나오기 전에는 매도하지 않습니다.
- 같은 날 여러 조건이 맞으면 순서대로 이어서 매도합니다 (예: 데드크로스와 RSI 50 하회가 같은 날 → 1과 2를 함께 매도).
- 전량 매도 후에는 포지션이 초기화되고, 다시 1단계 매수 조건을 기다립니다.
- "구름 이탈"의 기준은 `--exit` 옵션으로 고를 수 있습니다 (기본: 구름 **하단** 아래로 마감).

### 사용 지표

| 지표 | 설정 |
|---|---|
| RSI | 14일, Wilder 평활 방식 |
| MACD | EMA 12 / EMA 26, 시그널 9 |
| 일목균형표 | 전환선 9, 기준선 26, 선행스팬B 52, 26일 선행 |

오늘 날짜의 구름은 26거래일 전에 계산된 선행스팬 A·B로 그립니다. 따라서 지표가 계산되려면 최소 약 78거래일의 데이터가 필요합니다. 야후 파이낸스에서는 기본으로 최근 3년치를 받아옵니다.

## 3. 사용법

```bash
python common/shigeru_126.py [종목코드 ...] [옵션]
```

### 종목코드 입력 규칙

| 시장 | 입력 예 | 설명 |
|---|---|---|
| 한국 | `005930` | 6자리 숫자를 넣으면 코스피(`.KS`)로 먼저 조회하고, 없으면 코스닥(`.KQ`)으로 조회합니다 |
| 미국 | `AAPL`, `TSLA` | 야후 파이낸스 티커 그대로 |
| 일본 | `7203.T` | 야후 파이낸스 티커 그대로 |

여러 종목을 공백으로 구분해 한 번에 조회할 수 있습니다.

### 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--since YYYY-MM-DD` | (전체 기간) | 이 날짜부터 1:2:6 시뮬레이션을 시작합니다 |
| `--held {0,1,3,9}` | `0` | `--since` 시점에 **실제로 보유 중인** 단위 수. `--since`와 함께 써야 합니다 |
| `--exit {bottom,top}` | `bottom` | 구름 이탈 기준. `bottom` = 종가가 구름 하단 아래, `top` = 종가가 구름 상단 아래 |
| `--amount 금액` | (없음) | 종목당 **총 투자금**(종목 통화 기준). 지정하면 단계별 매수 금액·주수와 매도 비율을 함께 보여줍니다. `9000000`, `9,000,000` 모두 가능 |
| `--n N` | `10` | 화면에 보여줄 최근 신호 기록 개수 |
| `--csv 파일` | — | 야후 대신 CSV 파일의 데이터를 사용합니다 |

## 4. 사용 예시

### 여러 종목 한 번에 점검

```bash
python common/shigeru_126.py 005930 000660 AAPL 7203.T
```

과거 3년치 데이터로 처음부터 규칙을 적용해 보고, 그 결과로 **현재 어떤 단계에 있는지**와 **오늘 신호**를 보여줍니다.

### 실제로 보유 중인 종목 감시 (가장 실용적인 사용법)

8월 1일에 이미 9단위를 모두 매수해 둔 상태라면:

```bash
python common/shigeru_126.py 005930 --since 2026-08-01 --held 9
```

프로그램은 8월 1일부터 9/9 보유 상태로 시작해 매도 조건만 추적합니다. 매일 장 마감 후 실행해 매도 신호가 나왔는지 확인하면 됩니다.

`--held` 값은 실제로 체결한 단계에 맞춰 넣습니다.

| 실제 상황 | `--held` |
|---|---|
| 아직 매수 안 함 | `0` |
| 1단계(1)만 매수 | `1` |
| 2단계까지(1+2) 매수 | `3` |
| 3단계까지(1+2+6) 모두 매수 | `9` |

### 투자금을 넣어 매수 금액·주수 확인

```bash
python common/shigeru_126.py 005930 --amount 9000000
```

종목당 투자금 900만 원을 9단위로 나누어 단계별 매수 금액을 계산합니다.

| 단계 | 비율 | 900만 원일 때 |
|---|---|---|
| 1단계 (RSI 30 하회) | 1/9 | 1,000,000 |
| 2단계 (MACD 골든크로스) | 2/9 | 2,000,000 |
| 3단계 (구름 상단 돌파) | 6/9 | 6,000,000 |

- **매수 신호가 뜬 날**: 그 단계 금액과, 당일 종가로 살 수 있는 주수(소수점 버림)를 보여줍니다.
  ```
    🟢🟢 오늘 매수 신호 🟢🟢
       ▶ MACD 골든크로스: 2/9 매수  (종가 262,000.00)  → 2,000,000 매수 (약 7주)
  ```
- **신호가 없는 날**: 상태 줄에 다음 단계에서 살 금액과 현재가 기준 주수를 미리 보여줍니다.
  ```
    대기 중 — 다음 매수 조건: RSI 30 하회 (현재 47.5) / 다음 매수 금액 1,000,000 (현재가 기준 약 3주)
  ```
- **매도 신호가 뜬 날**: 현재 보유 수량 중 몇 분의 몇을 팔아야 하는지 보여줍니다. 실제로 산 주수는 매수 시점 가격에 따라 다르므로 주수 대신 비율로 표시합니다.
  ```
    🚨🚨 오늘 매도 신호 🚨🚨
       ▶ MACD 데드크로스: 1/9 매도  (종가 61,200.00)  → 보유 수량의 1/9
       ▶ RSI 50 하회 (47.3): 2/9 매도  (종가 61,200.00)  → 보유 수량의 2/8
  ```
  예를 들어 90주를 보유 중이라면 MACD 데드크로스에서 10주, 이어서 RSI 50 하회에서 남은 80주의 2/8인 20주를 팝니다. 구름 이탈 시에는 `보유 수량 전량`으로 표시됩니다.

> ⚠️ 금액은 **종목의 거래 통화** 기준입니다. `005930 AAPL --amount 9000000`처럼 섞어 넣으면 AAPL은 900만 **달러**로 계산됩니다. 통화가 다른 종목은 따로 실행하세요.
>
> ```bash
> python common/shigeru_126.py 005930 000660 --amount 9000000   # 원화
> python common/shigeru_126.py AAPL TSLA --amount 9000          # 달러
> ```

*(위 수치는 설명을 위한 예시입니다.)*

### 구름 이탈을 보수적으로 판단

```bash
python common/shigeru_126.py 005930 --exit top
```

종가가 구름 **상단** 아래로만 내려와도 전량 매도 신호를 냅니다. 기본값(`bottom`)보다 빨리 빠져나옵니다.

### CSV 파일로 분석

```bash
python common/shigeru_126.py --csv mydata.csv
```

CSV에는 다음 컬럼이 있어야 합니다. 날짜 순서는 섞여 있어도 자동으로 정렬됩니다.

```csv
Date,Open,High,Low,Close
2026-01-02,53000,53800,52700,53500
2026-01-05,53600,54200,53100,54000
...
```

## 5. 출력 읽는 법

```
======================================================================
■ 005930.KS   기준일 2026-10-08   종가 61,200.00
  RSI 47.3 | MACD -120.512 / 시그널 -85.204 | 구름 58,900.00 ~ 62,350.00

  🚨🚨 오늘 매도 신호 🚨🚨
     ▶ RSI 50 하회 (47.3): 2/9 매도  (종가 61,200.00)
  6/9 보유 — 다음 매도 조건: 구름 이탈선 58,900.00 하회 (현재가 61,200.00, 여유 +3.9%)

  최근 신호 기록 (최대 10건)
    2026-07-14  매수  1/9     55,100.00  RSI 30 하회 (29.4)
    2026-07-29  매수  2/9     56,800.00  MACD 골든크로스
    2026-08-20  매수  6/9     60,300.00  구름 상단 돌파
    2026-09-30  매도  1/9     62,000.00  MACD 데드크로스
    2026-10-08  매도  2/9     61,200.00  RSI 50 하회 (47.3)
```

*(위 수치는 설명을 위한 예시입니다.)*

| 항목 | 의미 |
|---|---|
| 첫 줄 | 조회한 심볼, 마지막 거래일, 종가 |
| 둘째 줄 | 현재 RSI, MACD와 시그널, 구름 하단 ~ 상단 |
| 🚨 오늘 매도 신호 | **마지막 거래일에** 발생한 매도 신호. 이것이 뜨면 매도를 검토해야 합니다 |
| 🟢🟢 오늘 매수 신호 | **마지막 거래일에** 발생한 매수 신호. 이것이 뜨면 해당 단계 매수를 검토합니다 |
| 오늘 신호 없음 | 마지막 거래일에는 아무 신호가 없음 |
| 상태 줄 | 현재 보유 단위와 **다음에 지켜볼 조건** |
| 최근 신호 기록 | 시뮬레이션 기간 동안 발생한 매수·매도 이력 |

상태 줄은 현재 단계에 따라 다음과 같이 바뀝니다.

| 상태 | 표시 내용 |
|---|---|
| 0/9 | `대기 중 — 다음 매수 조건: RSI 30 하회 (현재 …)` |
| 1/9 | `다음 매수 조건: MACD 골든크로스 (MACD-시그널 …)` — 값이 0을 넘어서면 골든크로스 |
| 3/9 | `다음 매수 조건: 종가가 구름 상단 … 돌파` |
| 9/9 이하(매도 단계) | 순서상 **바로 다음 매도 조건** (데드크로스 → RSI 50 → 구름 이탈선까지 남은 여유(%)) |

## 6. 매수 시작 종목 찾기 (`firstbuy/shigeru_start.py`)

`stock/stock_list_krx.csv`에 있는 KOSPI·KOSDAQ 종목 중 **일반주·우선주(약 2,700개, ETF·ETN 제외)** 를 모두 검사해서, **1:2:6의 1단계 매수 조건(RSI(14)가 30 아래로 내려감)** 이 발생한 종목을 찾아줍니다. 종목당 투자금을 넣으면 첫 1/9 매수 금액과 살 수 있는 주수도 알려줍니다.

찾은 종목은 화면에 출력하고, 동시에 **`firstbuy/shigeru_start_YYYYMMDD.csv`** 파일로 저장합니다(날짜는 데이터 기준일). 찾은 종목이 없으면 파일을 만들지 않습니다.

```bash
python firstbuy/shigeru_start.py --amount 9000000
```

### 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--amount 금액` | (없음) | 종목당 총 투자금(원). 1단계 매수 금액은 이 금액의 **1/9** |
| `--min-price 가격` | `5000` | 이 가격(원) **미만** 종목 제외. `--min-price 10000`처럼 바꿀 수 있고, `0`이면 제한 없음 |
| `--include-etf` | (꺼짐) | ETF·ETN도 포함해서 검사 |
| `--days N` | `1` | 최근 N거래일 안에 신호가 난 종목까지 포함. `1`이면 마지막 거래일만 |
| `--market {KOSPI,KOSDAQ}` | (전체) | 한 시장만 검사 |
| `--limit N` | (전체) | 리스트 앞에서부터 N개만 검사. CSV가 시가총액 순이므로 대형주 위주로 빠르게 볼 때 사용 |
| `--list 파일` | `stock/stock_list_krx.csv` | 종목 리스트 CSV (`종목코드,종목명,시장,종류` 컬럼) |
| `--out 파일` | `firstbuy/shigeru_start_YYYYMMDD.csv` | 결과 CSV 저장 경로 (`--amount`를 주면 `1단계금액`, `주수` 컬럼 포함) |

### 출력 예

```
==============================================================================
  🟢 1:2:6 매수 시작 종목 4개  (RSI 30 하회 → 1/9 매수)
  주가 5,000원 미만 제외
  종목당 투자금 9,000,000 → 1단계 매수 금액 1,000,000
==============================================================================
  1. 펩트론(087010, KOSDAQ)  신호일 2026-10-08  종가 91,500  RSI 27.4
       → 1,000,000 매수 (약 10주)
  2. 휴온스(243070, KOSDAQ)  신호일 2026-10-08  종가 19,000  RSI 29.0
       → 1,000,000 매수 (약 52주)
  ...

  다음 단계: MACD 골든크로스 시 2/9, 구름 상단 돌파 시 6/9 추가 매수
  매수 후 관리:  buynsell/portfolio.csv 에 체결 내역을 적고 python buynsell/shigeru_portfolio.py

  💾 결과 저장: .../shigeru126/firstbuy/shigeru_start_20261008.csv
```

저장되는 CSV 예:

```csv
종목코드,종목명,시장,신호일,기준일,종가,RSI,1단계금액,주수
087010,펩트론,KOSDAQ,2026-10-08,2026-10-08,91500.0,27.4,1000000,10
243070,휴온스,KOSDAQ,2026-10-08,2026-10-08,19000.0,29.0,1000000,52
```

*(2026-10-08 기준 `--market KOSDAQ --limit 400` 실행 결과 일부. 투자 추천이 아닙니다.)*

- RSI가 낮은 종목부터 정렬됩니다.
- 1주 가격이 1단계 금액보다 비싸면 `금액 부족`으로 표시됩니다.
- 매수한 뒤에는 출력 하단의 안내처럼 체결 내역을 `buynsell/portfolio.csv`에 적고 `buynsell/shigeru_portfolio.py`로 다음 단계와 매도 신호를 관리하세요(7절).

### 알아둘 점

- **전 종목 검사는 약 2분**(ETF·ETN 포함 시 약 4~5분) 걸립니다(100종목씩 묶어서 받음). 빠르게 보려면 `--limit`이나 `--market`을 쓰세요.
- 일반주·우선주 구분은 종목 리스트의 `종류` 컬럼(네이버 증권의 `stock`/`etf`/`etn` 분류)을 사용합니다. 스팩(SPAC)·리츠도 `stock`으로 분류되어 결과에 나올 수 있습니다.
- `종류` 컬럼이 없는 예전 형식의 `stock/stock_list_krx.csv`를 쓰면 ETF·ETN을 거르지 못하고 경고를 출력합니다. 파일을 지우고 `python stock/stock_list.py`로 다시 받으세요.
- 5,000원 기준은 **마지막 거래일 종가**(장중에는 현재가)로 판단합니다.
- **장중(09:00~15:30)에 실행하면** 야후 일봉의 오늘 봉을 네이버 증권의 **실시간 현재가**(시가·고가·저가·현재가)로 바꿔서 RSI를 계산합니다. 화면에는 `현재가(장중 11:15) 64,500`처럼 표시되고, 저장 CSV는 `종가` 대신 `현재가` 컬럼과 `시세시각` 컬럼이 들어갑니다. 장중 신호는 장 마감 전까지 바뀔 수 있습니다.
- 상장폐지·신주인수권처럼 야후에 데이터가 없는 종목이나, 상장한 지 얼마 안 되어 지표를 계산할 수 없는 종목(약 80거래일 미만)은 자동으로 빠지고 개수만 표시됩니다.
- 이 프로그램은 "오늘 RSI가 30 아래로 **내려간**" 종목만 찾습니다. 이미 며칠째 30 아래에 머물러 있는 종목은 `--days`를 늘려야 보입니다.
- 종목 리스트를 최신으로 갱신하려면 `stock/stock_list_krx.csv`를 지우고 `python stock/stock_list.py`를 실행하세요.

## 7. 보유 종목 관리 (`buynsell/shigeru_portfolio.py`)

실제로 매매한 기록을 CSV에 적어 두면, 종목별로 **지금 얼마를 몇 주 사야 하는지, 몇 주 팔아야 하는지** 알려줍니다.

```bash
cp buynsell/portfolio_sample.csv buynsell/portfolio.csv   # 샘플을 복사해서 내 기록으로 고쳐 쓰기
python buynsell/shigeru_portfolio.py                       # buynsell/portfolio.csv 읽기
python buynsell/shigeru_portfolio.py portfolio_sample.csv  # 다른 파일 읽기
```

파일 이름만 적었는데 현재 위치에 그 파일이 없으면 `buynsell/`에서 같은 이름을 찾아 읽습니다. 다른 위치의 파일은 경로를 함께 적으면 됩니다.

### CSV 작성법

한 줄이 **체결 한 건**입니다. 매수·매도할 때마다 한 줄씩 추가하세요.

```csv
종목코드,종목명,날짜,구분,단계,가격,수량,투자금
034020,두산에너빌리티,2026-06-08,매수,1,85800,11,9000000
034020,두산에너빌리티,2026-06-16,매수,2,103300,19,
034020,두산에너빌리티,2026-09-08,매수,6,89500,67,
034020,두산에너빌리티,2026-09-17,매도,1,85400,11,
034020,두산에너빌리티,2026-09-23,매도,2,81700,22,
```

| 컬럼 | 적는 값 | 예 |
|---|---|---|
| `종목코드` | 한국 종목은 6자리 코드, 해외는 야후 티커 | `034020`, `AAPL` |
| `종목명` | 화면 표시용 (아무 이름이나 가능) | `두산에너빌리티` |
| `날짜` | 체결일 `YYYY-MM-DD` | `2026-06-08` |
| `구분` | `매수` 또는 `매도` | `매수` |
| `단계` | 아래 표 참고. **1, 2, 6 중 하나** | `1` |
| `가격` | 실제 체결 단가 | `85800` |
| `수량` | 실제 체결 주수 | `11` |
| `투자금` | 그 종목의 **총 투자금(9단위 전체)**. 종목의 첫 줄에만 적으면 됩니다 | `9000000` |

`단계` 값의 의미:

| 단계 | 매수일 때 | 매도일 때 |
|---|---|---|
| `1` | RSI 30 하회 (1/9) | MACD 데드크로스 (1/9) |
| `2` | MACD 골든크로스 (2/9) | RSI 50 하회 (2/9) |
| `6` | 구름 상단 돌파 (6/9) | 구름 이탈 → **남은 물량 전량** |

- 줄 순서는 상관없습니다. 날짜순으로 정렬해서 처리합니다.
- 엑셀에서 저장해 `034020`이 `34020`이 되어도 6자리로 자동 보정됩니다.
- 보유 주수가 0이 되면 그 종목의 사이클이 끝난 것으로 보고, 다음 매수는 다시 1단계부터 시작합니다. 같은 종목의 다음 사이클도 같은 파일에 이어서 적으면 됩니다.
- `투자금`을 비워 두면 `--amount`로 준 값을 씁니다. 둘 다 없으면 매수 주수를 계산하지 못합니다(매도 주수는 보유 주수로 계산하므로 문제없음).

[buynsell/portfolio_sample.csv](buynsell/portfolio_sample.csv)에는 다섯 가지 상황이 들어 있습니다(종목당 투자금 900만 원, 날짜·가격은 실제 신호일의 종가).

| 종목 | 상황 |
|---|---|
| SK이노베이션 | 1·2·6 매수 후 구름 이탈로 전량 매도 → 사이클 종료 |
| 두산에너빌리티 | 1·2·6 매수 후 1·2 매도 → 6/9 보유 중, 구름 이탈 감시 |
| 현대차 | 1·2 매수 → 3/9 보유, 구름 상단 돌파 대기 |
| 현대모비스 | 1 매수만 기록 → 그 뒤 MACD 골든크로스를 **놓친 상태** |
| HD한국조선해양 | 1 매수 → MACD 골든크로스 대기 |

### 계산 방식

마지막 기록일 **다음 거래일부터 오늘까지** 1:2:6 규칙을 다시 적용해서, 그사이에 신호가 났는데 기록이 없으면 "지금 해야 할 일"로 알려줍니다.

| 행동 | 금액·주수 계산 |
|---|---|
| 매수 | 투자금 × 단계/9 → **현재가**로 나눈 주수(소수점 버림) |
| 매도 (1, 2) | 그 시점 보유 주수 × 매도 단위 / 보유 단위 (반올림) — 예: 97주·9단위에서 1/9 → 11주 |
| 매도 (구름 이탈) | 보유 주수 전량 |

### 출력 예

```
■ 현대모비스(012330.KS)   기준일 2026-10-08   종가 359,000.00
  보유 1/9 단위 (1 매수), 2주, 평균단가 383,000, 평가손익 -6.3% | 투자금 9,000,000
  마지막 기록 2026-09-16

  ▶ 지금 해야 할 일 (마지막 기록 이후 발생한 신호)
    🟢 매수 2/9  [2026-10-01 MACD 골든크로스]  → 2,000,000 매수 = 약 5주 (현재가 359,000 기준)
    ※ 지난 날짜의 신호는 놓친 신호입니다. 지금 가격으로 따라갈지 판단하세요.

■ 두산에너빌리티(034020.KS)   기준일 2026-10-08   종가 78,000.00
  보유 6/9 단위 (1·2·6 매수), 64주, 평균단가 91,784, 평가손익 -15.0% | 투자금 9,000,000
  마지막 기록 2026-09-23

  ✅ 지금은 할 일 없음
  6/9 보유 — 다음 매도 조건: 구름 이탈선 76,750.00 하회 (현재가 78,000.00, 여유 +1.6%)

##############################################################################
  오늘 할 일 1건
    - 현대모비스: 매수 2/9 5주  (MACD 골든크로스)

  💾 할 일 저장: .../shigeru126/buynsell/shigeru_todo_20261008.csv

```

*(2026-10-08 기준 `portfolio_sample.csv` 실행 결과 일부. 투자 추천이 아닙니다.)*

- 할 일이 있으면 `buynsell/shigeru_todo_YYYYMMDD.csv`로 저장합니다(`--out`으로 경로 변경).
- 실제로 매매했으면 **그 체결 내역을 CSV에 한 줄 추가**하세요. 그래야 다음 실행 때 같은 신호를 다시 알려주지 않습니다.
- 매수 주수는 신호일 종가가 아니라 **현재가**로 계산합니다. 놓친 신호를 지금 따라 살지는 직접 판단하세요.
- **장중(09:00~15:30)에 실행하면** 오늘 봉을 네이버 증권의 **실시간 현재가**로 만들어 신호·평가손익·주수를 계산합니다. 첫 줄이 `현재가(장중 11:15) 73,100.00`처럼 바뀌고, 오늘 날짜 신호에는 "장 마감 전까지 바뀔 수 있습니다" 안내가 붙습니다. 할 일 CSV에는 `시세시각` 컬럼이 추가됩니다.

## 9. 알아둘 점

- **종가 기준**입니다. `common/shigeru_126.py`는 장중에 실행하면 야후의 (약 20분 지연된) 그 시점 가격이 종가처럼 쓰여 결과가 장 마감 후와 달라질 수 있습니다. `firstbuy/`와 `buynsell/` 프로그램은 장중이면 네이버 실시간 현재가로 오늘 봉을 계산하고 `현재가(장중 HH:MM)`로 표시합니다(장 마감 전까지 신호가 바뀔 수 있음).
- **매수 도중(1/9, 3/9)에는 매도 규칙이 작동하지 않습니다.** 3단계 매수가 나오기 전까지 가격이 계속 하락해도 프로그램은 매도 신호를 내지 않으므로, 손절은 별도로 판단해야 합니다.
- MACD 데드크로스와 RSI 50 하회 매도는 한 사이클에 각각 **한 번씩만** 발생합니다.
- 매수 1단계는 RSI가 30 아래로 **내려가는 순간**에만 발생합니다. 이미 30 아래에 머물러 있는 상태에서는 새로 신호가 나지 않습니다. 반면 매도의 RSI 조건은 50 **미만이기만 하면** 발생합니다.
- `--since` 없이 실행하면 3년 전 데이터부터 시뮬레이션하므로, 실제 보유 상태와 프로그램이 계산한 상태가 다를 수 있습니다. 실제로 보유한 종목은 `--since`와 `--held`로 상태를 맞춰 주세요.
- `--held`는 단계 경계값(0, 1, 3, 9)만 받습니다. 이미 일부를 매도한 상태(예: 6/9)를 지정하는 기능은 없습니다.
- 데이터는 야후 파이낸스에서 받아옵니다. 네트워크 상태나 야후 측 사정에 따라 조회가 실패하거나 최신 거래일이 늦게 반영될 수 있습니다.
- 수정주가가 아닌 **원주가**(`auto_adjust=False`)를 사용합니다. 액면분할 등이 있었던 종목은 지표가 왜곡될 수 있습니다.

- 기본 입출력 경로는 **실행 위치가 아니라 프로그램 파일 위치 기준**입니다. 어디서 실행해도 종목 리스트는 `stock/`에서, 매매 기록은 `buynsell/`에서 읽고, 결과는 `firstbuy/`·`buynsell/`에 저장합니다.
- `firstbuy/`, `buynsell/`의 프로그램은 `common/shigeru_126.py`의 규칙·지표를 그대로 가져다 쓰므로 판단 기준이 같습니다.

`common/shigeru_126.py` 내부 구성:

| 함수/클래스 | 역할 |
|---|---|
| `load_yahoo`, `load_csv` | 일봉 데이터 로드 |
| `add_indicators` | RSI, MACD, 일목 구름 계산 및 교차 신호 생성 |
| `Position` | 보유 단위와 진행 단계를 담는 상태 객체 |
| `step` | 하루치 데이터로 1:2:6 규칙 적용 |
| `run` | 기간 전체 시뮬레이션 |
| `buy_money` | 투자금 중 해당 단계 금액과 살 수 있는 주수 계산 |
| `positive_amount` | `--amount` 입력값 검증 |
| `format_today` | 오늘의 매수/매도 신호 블록 생성 |
| `format_summary` | 여러 종목 조회 시 마지막 요약 생성 |
| `next_hint`, `report` | 결과 출력 (`report`는 요약용 신호를 반환) |

pip install pytest
